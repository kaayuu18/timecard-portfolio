# タイムカード・勤怠管理アプリ

職業訓練で作成したJava/Spring Bootの学習作品を、配布しやすいH2版に改修したものです。
従業員の出退勤打刻、休憩、シフト、勤怠修正と給与の参考集計を扱います。

## 主な機能

- 従業員IDを入力して出勤・退勤・休憩開始・休憩終了を記録
- 今日の打刻一覧
- 管理者ログイン、従業員登録・検索・編集・削除
- 月間カレンダー、シフト登録・編集・削除
- 勤怠の追加・編集・削除
- 日給と月間勤務時間の参考集計（26日〜翌月25日の締め期間）
- H2のファイル保存とサンプルデータの初回作成

## 技術

Java 21 / Spring Boot 3.4.0 / Spring MVC / Spring Data JPA /
Spring Security / Thymeleaf / H2 / Gradle / HTML・CSS・JavaScript

コード構成：controllerは画面からの要求、entityはDBのデータ、
repository/daoはDB検索と保存、serviceは計算や認証を担当します。

## 起動方法

Java 21を用意し、このREADMEとbuild.gradleがあるフォルダで実行します。
初回ビルドにはインターネット接続が必要です。MySQLは不要です。

Mac / Linux：

```bash
sh gradlew bootRun
```

WindowsのPowerShell：

```powershell
.\gradlew.bat bootRun
```

起動後、ブラウザで http://localhost:8080/timecard を開きます。
管理者ページは http://localhost:8080/admin です。

新規DBの管理者ログイン：`admin` / `demo1234`（公開されたデモ専用の認証情報）。
実在の従業員の個人情報や本番の認証情報は登録しないでください。
本作品はローカルの動作確認用で、127.0.0.1からの接続に限定しています。

## サンプルデータ

新規DBでは初期アカウントadmin/demoと、名前にサンプル_が付く従業員5人を作成します。
過去6日分の退勤済み勤怠30件、今日の出勤中の勤怠2件、今日から7日分のシフト35件を用意します。
日付は最初の起動日が基準です。従業員IDは従業員一覧で確認してください。

サンプル追加済みの記録をDBに残し、再起動では重複させません。
既存のアカウント・勤怠・シフトを上書きしません。

## JARで実行する場合

```bash
sh gradlew bootJar
java -jar build/libs/timecard-0.0.1-SNAPSHOT.jar
```

相手にビルド済みJARを渡す場合、実行に必要なのはJava 21とブラウザです。
ソースコードを取得してビルドする場合は、Gradle Wrapperが依存ライブラリを取得します。
GitHubのリポジトリURLはソース共有用で、ブラウザでアプリを実行するURLとは別です。

データは起動したフォルダ内の`data/timecard.mv.db`へ保存します。
再起動時も同じフォルダから実行してください。DBファイルはGitの対象から除外しています。

- 従業員情報画面のテンプレート名の修正
- 主要コードへの簡単な説明コメント

## 確認状況と残っていること

修正したJavaの計算処理を簡易のDB・フレームワーク代替で実行し、休憩30/45/60分、
日給・残業、月間勤務時間の小数合計、空の月を確認しました。
サンプル件数、再実行時の重複防止、既存アカウントの保持も同じ方式で確認しています。
この確認は実際のH2接続やブラウザ操作を通した全体テストとは異なります。

H2版の全画面・全操作、実際のDBを含む保存と再起動、異常入力の確認はまだ完了していません。
給与計算は学習用の参考値で、実際の給与計算に必要な全ルールには対応していません。
以前の版で保存した誤った勤怠は、自動で修正しません。
