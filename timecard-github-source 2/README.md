# 勤怠管理アプリ：起動手順

1. ZIPを展開し、フォルダーごと書き込みできる場所に置きます。
2. Java 21（JDK）をインストールします。
3. Macは `Start-Mac.command`、Windowsは `Start-Windows.bat` を開きます。
4. ブラウザーで http://localhost:8080/timecard を開きます。終了は起動した画面で Ctrl+C。

Macで実行権限がない場合は、そのフォルダーのターミナルで `chmod +x Start-Mac.command` を実行します。WindowsはJAVA_HOMEをJDK 21の場所に設定してください。

同梱JARがある場合はGradleや通信不要で起動します。ソースを変更した場合は `./gradlew clean test bootJar`（Windowsは `gradlew.bat clean test bootJar`）を実行し、build/libs の `*-SNAPSHOT.jar` を app/timecard.jar にコピーしてから再起動してください。初回ビルドはインターネット接続が必要です。

## ログイン
新しいH2データベースでは管理者 `admin`、従業員 `demo`、パスワードは両方 `demo1234`。デモ用のアカウントです。実際に利用する前に変更してください。従業員IDは管理者の従業員一覧で確認できます。

## 操作
- 打刻：従業員IDを入力して出勤→休憩→戻り→退勤。ページを遷移せず一覧と結果が更新されます。JavaScriptが無効でも通常のフォームで打刻できます。
- シフト：管理者で `/shiftedit` を開き、登録・変更・削除。既存カレンダーの操作も引き続き利用できます。
- 給与：従業員一覧から給料管理。前月26日〜当月25日の集計、残業合計を表示します。
- 計算：実働分数から計算、1日8時間超は1.25倍。日給の1円未満は切り捨て。表示時間は小数2桁切り捨てのため給与の逆算には使いません。週40時間超・深夜・休日割増や税・社会保険は未対応の参考計算です。日付をまたぐ勤務・複数回の休憩は未対応です。

## データ保存・バックアップ
H2がデフォルトで、MySQLの準備は不要です。起動フォルダーの `data/` に保存し、再起動しても保持します。バックアップはアプリを終了してからdataフォルダーをコピーしてください。既存データを使う場合も、先にバックアップしてください。ZIPには元の個人データを含めていません。

127.0.0.1のみで待ち受けます。8080が使用中の場合は他の起動を終了してください。ポート変更は `java -jar app/timecard.jar --server.port=8081`。アクセス先も8081に変えます。
