タイムカード H2お試し版（Java 21）

1. ZIPを展開し、VS Codeでtimecard-h2フォルダを開く。
   元のMySQL版とは別のフォルダで試してください。
2. Macのターミナルでbuild.gradleのあるフォルダに移動して実行：
   sh gradlew bootRun
   初回のビルドにはインターネット接続が必要です。
3. ブラウザで http://localhost:8080/timecard を開く。
4. 管理者ログイン：名前 admin / パスワード demo1234
   初回の従業員ID：admin=1、demo=2（新規DBの場合）。
5. 終了はターミナルでControl+C。

相手に渡すアプリ本体を作る：
   sh gradlew bootJar
生成先：build/libs/timecard-0.0.1-SNAPSHOT.jar
このJARと説明書を渡し、相手はJava 21で以下を実行：
   java -jar timecard-0.0.1-SNAPSHOT.jar
その後 http://localhost:8080/timecard を開く。
JAR実行時はMySQL・Gradle・VS Code不要。ブラウザと書き込み可能なフォルダが必要。

データ：実行したフォルダのdata/timecard.mv.dbに保存され、再起動後も残ります。
起動するたびに同じフォルダから実行してください。
MySQLのデータは自動では移行しません。実データを送る必要はありません。
初期アカウントはDBが空の場合だけ作成し、既存のデータは上書きしません。
同じDBを開くアプリを同時に二つ起動しないでください。

変更点：Javaを21に設定、H2を既定に設定、テーブルの自動作成、
初回のテストアカウント作成、ログイン用サービスの取得を引数注入に変更。
MySQLのパスワードとビルド済みファイルはこのZIPに含めていません。
今回、休憩時間の分単位保存・月間勤務時間の小数集計・従業員情報の画面名を修正しました。

検証：この環境ではGradleのダウンロードがネットワーク制限で失敗したため、
Spring Boot全体のビルド・起動・ログイン・保存を実行しての確認は未完了です。
ゆたかさんのMacで起動し、動作を確認してください。

今回の更新：カレンダーを画面幅に合わせるHTML/CSSを同梱。
元のJava・HTML・JavaScriptの主要ファイルに、役割を説明する短いコメントを追加。
追加コメントで処理の動作は変更していません。

すでにH2版を使用中の場合：
アプリを停止して、今のプロジェクトのsrcフォルダを、このZIPのsrcで上書きしてください。
新しいフォルダに移す場合、既存のH2データを引き継ぐには停止中にdataフォルダもコピーします。
MySQL用のdataフォルダをコピーする操作ではありません。

3点修正版の検証：
修正した実際のKintaiService/SalaryControllerを、簡易のDB・フレームワーク代替を使いJavaで実行。
30分/45分/60分の休憩保存、8時間勤務から30分休憩を引いて7.5時間・日給7500円、
残業のあるケース、7.5時間と6.25時間の月間合計13.75時間（GET/POST双方）、
0.1時間と0.2時間の合計0.3時間、勤怠が空の月の合計0時間を確認済み。
personInfoの呼び出し名とHTMLファイル名の大文字・小文字も一致を確認。
これらは計算処理の検証で、実際のブラウザやDBを接続した全機能の確認ではありません。

以前の版で既に保存した勤怠は、自動で修正しません。
誤った休憩分数が残っている場合は勤怠の編集画面で正しい分数に直して保存する必要があります。
勤怠・シフトのサンプルデータを追加しました。

サンプル増量版：
既存のH2データベースにも、初回に一度だけ以下を追加します。
・サンプル従業員5人（名前にサンプル_が付く人）。時給1100〜1500円。
・過去6日分の退勤済み勤怠30件。通常勤務・短時間勤務・残業・休憩30分/60分の例。
・今日の出勤中の勤怠2件（今日の打刻一覧で確認できます）。
・今日から7日分のシフト35件。
初めて作るDBはadmin/demoも含め7人。既存の従業員・勤怠・シフトは変更しません。
同名の従業員がいる場合は、サンプル名の末尾に番号を付けて別の人を作ります。
追加済みマーカーをDBに保存し、再起動で重複しないようにします。
サンプル従業員のパスワードもdemo1234です。
日付は最初に追加した日を基準とし、再起動ごとには変更しません。

人数/勤怠/シフト件数、二度目の実行での重複防止、既存アカウントの保持、
同名衝突時の別アカウント作成を確認しました。
